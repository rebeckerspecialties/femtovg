# SVGenius icons

The 300 SVGs of the SVGenius benchmark (Chen et al., ACM MM 2025): 100 each of
its easy, medium and hard complexity levels, real-world icons from 24
application domains. Copied unmodified from `src/data/{easy,medium,hard}/process/`
of <https://github.com/ZJU-REAL/SVGenius> at
`18d56d738827304e74bb5037c9f9a3445dbbda93` (2025-11-10).

License: Apache License 2.0, in `LICENSE` (the repository's own).

The harness keys each file `svgenius__<file name>`, without the level, as it
did when the set was read from a checkout (see `harness/corpus_run/files.py`).
