## resvg's feBlend conformance cases (`corpus/resvg-feblend/`)

The non-BuseyBench example: linebender/resvg's ten `filters/feBlend` tests,
each an `feFlood` (lightblue, optionally on a subregion) blended with the
source graphic, `in=flood in2=SourceGraphic`. The harness maps a flood-first
chain onto a filled image over the flood's primitive subregion (converted to
linearRGB when the blend interpolates there) and blends it as the layer's
backdrop as for a noise chain, for the modes where the input order does not
matter (the source graphic is always the image the pass filters). `normal`,
`color-burn` and `hue` put the flood on top and stay unmapped (drawn
unfiltered, as before). Before is master with the same harness.
